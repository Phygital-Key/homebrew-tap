# Getting help

| You want to | Go to |
|---|---|
| Learn what the tap installs | [README](README.md) |
| Fix a problem with Phygital Key MCP | [Phygital Key MCP](https://github.com/Phygital-Key/phygital-key-mcp/issues) |
| Fix a problem with Phygital Key A2A | [Phygital Key A2A](https://github.com/Phygital-Key/phygital-key-a2a/issues) |
| Report a problem with a formula | [Open an issue](https://github.com/Phygital-Key/homebrew-tap/issues/new) |
| Report a security problem, privately | [Private report](https://github.com/Phygital-Key/homebrew-tap/security/advisories/new) ([SECURITY.md](SECURITY.md)) |
